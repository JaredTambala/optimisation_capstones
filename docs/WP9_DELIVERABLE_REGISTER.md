## Authoring rules

- Candidate-facing prose is projected from frozen WP8 sources or has one
  explicitly identified WP9 owner.
- Generated artefacts have exactly one writer.
- Author-side build controls are not described as candidate obligations.
- Candidate-facing assessment material is limited to the rubric; the AI-agent
  review method remains private.
- A file is retained only when it has a distinct professional or evidential
  purpose.
- WP10 assessment-policy work is not pulled into WP9.
